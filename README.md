## Tech Stack

- **Next.js 16** - React framework with App Router
- **React 18** + **TypeScript** - UI library with type safety
- **Tailwind CSS** - Utility-first CSS framework
- **Supabase** - Backend as a service (auth, database, storage)
- **HTML5 Canvas** - Interactive space background

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Vercel requires a paid plan to other devs to push to prod. Work around: update prod by editing readme and commiting changes.
